## 3. Structured Data (JSON-LD) Verification

1. **`EducationalOrganization` Schema:** Embedded globally in `src/app/layout.tsx` targeting EKAA Rise brand identity, Dubai location, and official website references.
2. **`Service` Schema with AED 100 Pricing:** Embedded globally with:
   - `@type: "Service"`
   - `name: "EKAA Rise Psychometric Test for Students"`
   - `price: "100"`
   - `priceCurrency: "AED"`
   - `areaServed: "Dubai, United Arab Emirates"`
3. **`BreadcrumbList` Schema:** Generated for all internal routes, maintaining crawlable hierarchical parentage.
4. **`Article` Schema:** Embedded on all individual guides with headline, datePublished, dateModified, and author attribution.

## 4. Crawl Control & Server Rendering

- **Robots.txt:** Generated at `/robots.txt` allowing general crawling, referencing `/sitemap.xml`, and disallowing internal staging paths and `/thank-you`.
- **Sitemap.xml:** Generated at `/sitemap.xml` containing all 34 canonical indexable URLs with change frequency and priority mapping.
- **Server-Side Rendered:** 100% of body copy, H1s, internal anchor tags (`<a href>`), and breadcrumbs are rendered into initial server HTML (verified via route smoke tests). No client-only hiding of indexable content.
- **Noindex Protection:** Strict `noindex, nofollow` implemented on `/thank-you`.
